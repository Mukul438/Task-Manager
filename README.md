# Task Manager — React + TypeScript

A simple and responsive Task Manager built using React, TypeScript, Vite, and CSS. This project demonstrates core React concepts and TypeScript fundamentals through a practical application.

## Features

- Add new tasks
- Mark tasks as completed or undo completion
- Delete tasks
- View total, completed, and pending task counts
- Display an empty-state message when no tasks exist
- Dark mode interface
- Responsive layout for smaller screens

## Tech Stack

- **React** — UI components and state management
- **TypeScript** — static typing and type safety
- **Vite** — development server and build tool
- **CSS** — styling and responsive layout
- **Git & GitHub** — version control and source code hosting

## Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed (optional, for cloning)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mukul438/Task-Manager.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Task-Manager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Build for Production

Run the following command to create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
